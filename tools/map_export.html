Export des cartes — Arcane Rift

Outil de debug local (à ouvrir directement dans un navigateur, aucun serveur requis — mais tools/dev_server.py fonctionne aussi). Génère les 6 cartes avec le vrai code de génération de niveau du jeu (AR.Level), sans brouillard de guerre : silhouette de terrain pixel-exacte + coffres / marchand / salles (ère 1 uniquement, les autres sont procédurales) / zone de l'arène de boss / position d'apparition de chaque monstre, y compris les monstres d'embuscade (ère 1) qui émergent du sol au déclenchement plutôt que d'être placés d'avance. À chaque évolution des maps (level_specs.js, génération procédurale dans level.js...), il suffit de recharger cette page (ou de cliquer sur « Régénérer ») pour obtenir des exports à jour — la seed fixe garantit un résultat reproductible tant que le code de génération ne change pas.
